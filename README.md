# Suit Kläder

## Om sidan

Suit Kläder är en webbplats för en herrklädesbutik med kostymer, skor, skjortor och finstrumpor. Sidan är skapad för att göra det enkelt att se olika kategorier och produkter.

## Skiss

Den färdiga sidan följer skissen med sidomeny, sökfält, hero-sektion och produktkort. Jag ändrade vissa detaljer och anpassade sidan för mobil.

## Funktionalitet

Besökaren kan klicka på "Köp" och få ett meddelande. Knappen "Se dina beställningar" scrollar till varukorgen och visar en beställningsruta som kan stängas.

På mobil kan besökaren öppna och stänga produktkategorier. JavaScript finns i app.js.

## AI-användning

Jag använde AI för att få hjälp med mobilanpassning och JavaScript.

För mobilanpassningen fick jag hjälp med media queries och CSS. Jag testade och anpassade koden efter min egen sida.

För JavaScript fick jag hjälp med att göra beställningsknappen interaktiv. Jag testade koden och anpassade den så att den fungerade med min HTML och CSS.

## Tekniska val

Jag använde Flexbox för huvudlayouten, sidomenyn och hero-sektionen. CSS Grid används för produktkorten.

Jag använde en media query med max-width: 768px för att anpassa sidan till mobil.

JavaScript används tillsammans med DOM-manipulation och addEventListener för att skapa interaktivitet.

Jag använder DOM-manipulation för att visa och dölja beställningsrutan och för att öppna och stänga mobilmenyn.

## Bedömning av AI-innehåll

Jag testade AI:s kod i mitt projekt och behöll det som fungerade. Jag ändrade koden när den behövde anpassas till min design och funktionalitet.

Jag testade bland annat beställningsrutan, scrollningen och mobilmenyn och försökte förstå koden innan jag använde den.
